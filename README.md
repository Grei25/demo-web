# Лесная Гавань — сайт базы отдыха

Демонстрационный самописный сайт базы отдыха на 6 страниц: главная, СПА и баня, ресторан, развлечения, контакты и политика конфиденциальности. Сделан на чистом HTML, CSS и JavaScript — без сборки, фреймворков и зависимостей. Подходит для обычного хостинга, GitHub Pages или Netlify.

## Страницы

| Файл | Содержание |
| --- | --- |
| `index.html` | Главная: hero, преимущества, о базе, номера, СПА, ресторан, развлечения, отзывы, галерея, форма бронирования |
| `spa.html` | СПА и баня: услуги, атмосфера, прайс, форма записи |
| `restaurant.html` | Ресторан «Сосны»: о ресторане, меню, банкеты, бронирование стола |
| `entertainment.html` | Развлечения: активности, прокат, территория, сезоны |
| `contacts.html` | Контакты: карточки, карта, как добраться, форма брони, FAQ |
| `privacy.html` | Политика конфиденциальности |

## Как посмотреть локально

Просто откройте `index.html` в браузере. Для карты, шрифтов и фотографий нужен интернет.

Либо запустите локальный сервер из папки проекта:

```bash
npx serve .
# или
python -m http.server 8000
```

## Что заменить перед запуском

1. **Название, контакты, адрес и соцсети.** Сейчас везде стоят демонстрационные данные: «Лесная Гавань», `+7 (495) 120-45-67`, `stay@lesnaya-gavan.ru`, деревня Сосновка. Замените поиском по проекту.
2. **Фотографии.** Используются временные изображения с Unsplash по прямым ссылкам. Замените их на реальные фото базы: положите файлы в `assets/img/` и поменяйте `src` у `<img>`. Если внешнее фото не загрузится, автоматически покажется локальная заглушка `assets/img/fallback.svg`.
3. **Тексты, цены, меню и номера.** Приведите к контенту со старого сайта и актуальному прайсу.
4. **Карта.** В `contacts.html` замените iframe OpenStreetMap на реальные координаты (Яндекс Карты, Google Maps или 2ГИС).
5. **Формы.** Сейчас они работают в демо-режиме: проверяют поля и показывают сообщение об успехе, но никуда не отправляют данные. Подключение описано ниже.
6. **Политика конфиденциальности.** Проверьте реквизиты оператора и текст с юристом.
7. **Домен.** После переноса обновите ссылки в `canonical`/Open Graph, если они появятся.

## Как подключить формы

Все формы помечены атрибутом `data-demo-form`. Обработчик находится в `js/main.js` (блок «Демонстрационная отправка форм»).

Варианты:

- **Сервис форм** (Formspree, Getform, Web3Forms): задайте `action` и `method="POST"` у формы, уберите `data-demo-form` и встроенный обработчик.
- **CRM**: отправляйте `fetch` на вебхук Bitrix24 или amoCRM.
- **Telegram**: Cloudflare Worker / небольшой серверный обработчик, который пересылает заявку в чат.
- **Почта**: PHP-скрипт на хостинге (`mail()` или SMTP) — если хостинг поддерживает PHP.

После подключения формы стоит добавить защиту от спама (honeypot или капчу).

## Публикация на GitHub Pages

1. Откройте репозиторий → **Settings** → **Pages**.
2. **Source**: Deploy from a branch, ветка `main`, папка `/ (root)`.
3. Сайт будет доступен по адресу `https://Grei25.github.io/demo-web/`.

## Деплой на обычный хостинг

Загрузите все файлы по FTP/SFTP в корень домена. Сборка и база данных не нужны. Для HTTPS включите SSL-сертификат в панели хостинга.

## Технические детали

- Шрифты: Cormorant Garamond (заголовки) и Manrope (текст), Google Fonts.
- Иконки: встроенные SVG, без сторонних библиотек.
- Анимации: IntersectionObserver, уважает `prefers-reduced-motion`.
- Формы: нативная валидация, демо-отправка, сброс.
- Галерея: лёгкий лайтбокс на `<dialog>`.
- SEO: заголовки, описания, Open Graph, семантическая разметка.
- Доступность: skip-link, aria-атрибуты, фокус-стили, alt у изображений.
